# 🌱 Calculadora de Emissão de CO2

Uma aplicação web moderna para cálculo de emissão de CO₂ baseada em:

- origem;
- destino;
- meio de transporte;
- distância real calculada por API pública.

O projeto possui visual premium responsivo, suporte a tema claro/escuro e comparação inteligente entre diferentes meios de transporte.

---

# ✨ Preview

## Funcionalidades

✅ Cálculo real de distância via API pública  
✅ Comparativo entre meios de transporte  
✅ Estimativa de emissão de CO₂  
✅ Estimativa de créditos de carbono  
✅ Tema Dark / Light  
✅ Layout responsivo  
✅ Interface moderna e minimalista  
✅ Inputs inteligentes com sugestões  
✅ Seleção única de modal de transporte  
✅ Cards comparativos dinâmicos
